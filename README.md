# 📝 AI Notes Summarizer

An AI-powered study assistant that helps students turn lengthy notes into concise and easy-to-understand summaries.

> 🚧 **Status:** Currently in development

## 📌 About

AI Notes Summarizer is a full-stack web application built with React and Node.js.

The goal is to make studying faster by allowing users to enter their notes and receive AI-generated summaries.

The project is being developed step-by-step, starting with a basic notes summarization system and gradually expanding into a complete AI-powered study assistant.

## ✨ Current Features

- 📝 Enter study notes
- ⚛️ React frontend
- 🟢 Node.js backend
- 🚂 Express.js REST API
- 🔗 React and Node.js integration
- 📋 Display generated summaries
